# Assets

This directory stores reusable fonts, images, music, sound effects, and battery profiles, organized by asset type.

Keep each asset in the matching subdirectory and document its destination, naming, integration method, and source/license. Do not mix binary assets with Markdown documentation.

## Fonts

Store reusable font files and generated font sources in `fonts/`.

- Use descriptive names that include the family, weight, size, and format when relevant.
- Document the source, license, character range, conversion command, and expected destination.
- Check Flash and internal-RAM impact before adding a font; the ESP32-C3 has no PSRAM.
- Do not commit fonts whose license does not permit redistribution.

| File | Size and format | Purpose, source, and license |
| --- | --- | --- |
| [`fonts/wm_font_16.c`](fonts/wm_font_16.c) + `wm_font_16.bin` | 16 px, 4 bpp, 7001 glyphs, 870 KB bitmap | UI text. ASCII from Inter Medium; punctuation and all 6763 GB2312 ideographs from Noto Sans CJK SC Medium. |
| [`fonts/wm_font_16_ext.c`](fonts/wm_font_16_ext.c) + `wm_font_16_ext.bin` | 16 px, 2 bpp, 14139 glyphs, 905 KB bitmap | Fallback for rare name characters: the rest of U+4E00..U+9FA5, Noto Sans CJK SC Medium. |
| [`fonts/wm_font_28.c`](fonts/wm_font_28.c) + `wm_font_28.bin` | 28 px, 2 bpp, 7001 glyphs, 1.3 MB bitmap | Headlines and attendee names. ASCII from Inter SemiBold; GB2312 from Noto Sans CJK SC Bold. Needs `CONFIG_LV_FONT_FMT_TXT_LARGE=y`. |

Inter and Noto Sans CJK are both distributed under the SIL Open Font License 1.1, which
permits embedding and redistribution. The files are generated by
[`tools/gen_wm_fonts.py`](../tools/gen_wm_fonts.py) (Pillow 12.3 and fontTools; run
`python3 tools/gen_wm_fonts.py --inter-dir <dir> --noto-dir <dir>` from the repository
root) for LVGL 9.5 `fmt_txt`. Glyph tables are C source; glyph bitmaps are binary blobs
linked through `EMBED_FILES` in [`main/CMakeLists.txt`](../main/CMakeLists.txt), so they
stay in Flash and use no RAM. The fallback chain is `wm_font_28` -> `wm_font_16` ->
`wm_font_16_ext` -> `lv_font_montserrat_14`. Characters outside ASCII, the listed
punctuation, and U+4E00..U+9FA5 render as the LVGL placeholder box.
[`tests/test_wm_font_coverage.py`](../tests/test_wm_font_coverage.py) checks that every
character in the firmware's UI strings is covered.

## Images

Store reusable source images and generated display assets in `images/`.

| File | Dimensions and format | Use and source |
| --- | --- | --- |
| [`images/home.jpg`](images/home.jpg) | 3840 × 2160, JPEG | Product hero image embedded in both project README files to foreground AI Passport and its open, maker-oriented identity. |
| [`images/readme-hardware-specs.png`](images/readme-hardware-specs.png) | 2172 × 724, PNG RGBA | Optional technical infographic retained as a reference asset; it is no longer used as the homepage hero. Generated for this repository with the built-in image generation tool on 2026-09-17; the six labels and values were checked against the documented hardware contract. |
| [`images/logo-wordmark.png`](images/logo-wordmark.png) | 1648 × 336, PNG RGBA | Transparent black wordmark extracted from the repository's original `images/logo.png`; embedded in both project README files for light backgrounds. |
| [`images/logo-wordmark-dark.png`](images/logo-wordmark-dark.png) | 1648 × 336, PNG RGBA | White version of the extracted wordmark, used by the README `<picture>` element when GitHub is in dark mode. |

- Use descriptive names and document dimensions, pixel format, conversion steps, and destination.
- Prefer formats suitable for the 240 × 320 RGB565 display and account for Flash and internal RAM.
- Preserve editable sources where licensing permits, and record the source and license.
- Never commit device QR secrets, credentials, or personal data in images.

## Music and sound effects

Store reusable music and sound-effect sources in `music/`.

- Document the source, license, sample rate, bit depth, channels, conversion command, and destination.
- Prefer 16 kHz, 16-bit mono PCM when it matches the current BSP audio path.
- Check Flash and internal-RAM cost before embedding audio; stream or chunk long recordings.
- Do not commit media without redistribution permission.

## Battery profiles

[`battery/wanli-500mah-profile2-xil40x-20261020.txt`](battery/wanli-500mah-profile2-xil40x-20261020.txt)
contains the supplied CW2017 profile for the Wanli New Energy 500 mAh cell
(profile2, XIL40X, 2026-10-20). It is an unchanged copy of the project-supplied
file, retained at the maintainer's request for this firmware update. Its
original filename is recorded in the paired Chinese document. No separate
license was included in the supplied file.

The format is 80 lines of two hexadecimal digits, one byte per line in register
order. The BSP embeds those bytes in `components/bsp/src/bsp_battery.c`; the
host gate checks the source file and initializer for an exact match. Text-file
SHA-256: `7ea96eba4634f4495a37c25ffacd54c1deaa0693b162c892d671a2ba68460919`.
Decoded 80-byte SHA-256:
`fa7365671093ef449c5bdcfb4adb279e3d275f888109f50b6b2f21e9b96220d5`.
This is a fuel-gauge profile, not a charging configuration or a generic profile
for every 500 mAh cell; see the [hardware guide](../docs/hardware-design/AI_HARDWARE_DEVELOPMENT_GUIDE.md#9-cw2017-fuel-gauge).
